# 先确认前提：React 已会，目标是 pstack 的判断力

用户已具备 React 开发能力，明确表示教学载体必须是 React 应用，但 React 本身不是学习内容。真正要学的是 pstack 的 24 条原则与 23 个 playbook，深度要求是"理解并会用"，站点用途是自己长期复习。

**Implications**：后续课程不再安排任何 React 教学，直接进入原则与判断；每节课的产出同时是站点里可长期复习的一个单元，所以内容必须写进 `src/content/`，而不是一次性的 HTML。

**Evidence**：用户在被问及 React 起点时，直接否掉了"React 练手场"的定位，改为"用 React 实现，但不用纯 HTML 建教学站"。
